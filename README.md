# 3D Basketball Game

A simple 3D basketball game made in Unity using C#.

## Features

* Player movement
* Ball dribbling
* Charge-based throwing
* Real-time trajectory prediction
* Physics-based ball movement
* Automatic ball return
* Score system
* Win condition: 10 goals
* UI controls

## Controls

* Left / Right buttons: Move player
* Hold Throw button: Charge throw
* Release Throw button: Throw ball
* Space: Hold ball above head

## Technologies

* Unity
* C#
* Rigidbody Physics
* Line Renderer
* Unity UI
* TextMeshPro

## How to Run

1. Open the project in Unity.
2. Open the main scene.
3. Press Play.
4. Tap "Tap to Start" and begin playing.

## Goal

Score 10 goals to win the game.
